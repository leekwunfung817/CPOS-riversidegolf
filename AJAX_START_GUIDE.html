1️⃣ Basic Setup - 3 Simple Steps

Step 1: Include JavaScript Manager

Add this to your HTML file before the closing </body> tag:

<script src="./price_manager.js"></script>

Step 2: Create Price Display Cells

Replace your price display cells with:

<!-- Before: <td><?php getSinglePrice(...) ?></td> --> <!-- After: --> <td id="workday-hourly-price" class="price-cell"></td>

Step 3: Load Prices via JavaScript

<script> document.addEventListener('DOMContentLoaded', function() { // Load a price into the cell priceManager.loadPriceIntoCell( document.getElementById('workday-hourly-price'), 'golf_price', // table name 'workday', // period 'general_bay', // price category 'hourly' // identity/user type ); }); </script>

2️⃣ Authentication & Security

⚠️ Important: Users must be logged in via configuration-administraion.php before they can access the AJAX API.

Session Variables Checked:

Variable Purpose Example
$_SESSION["management"] Authentication check (must exist) md5 hash
$_SESSION["identity"] User role admin, manager, full-time, part-time
$_SESSION['name2'] Display name User Full Name

What Happens if User is Not Logged In?

The API returns HTTP 401 with error message:

{ "success": false, "error": "User not authenticated. Please login first." }

3️⃣ Available API Endpoints

Get a Single Price

GET /price_api.php?action=get&table=golf_price&period=workday&price_category=general_bay&identity=hourly
Parameter Required Valid Values
action Yes get
table Yes golf_price, golf_price_2
period Yes workday, holiday, holiday_19To22
price_category Yes general_bay, sand_bay, pickle_ball, vip
identity No* hourly, student, disabled

*Not needed for sand_bay and vip categories

Update a Price

POST /price_api.php Content-Type: application/x-www-form-urlencoded action=update&table=golf_price&period=workday&price_category=general_bay&identity=hourly&new_price=150

Get All Prices List

GET /price_api.php?action=get_prices_list&table=golf_price&period=workday

4️⃣ Practical Code Examples

Example 1: Load Single Price

// Load workday regular price for general bay const cell = document.getElementById('workday-hourly'); priceManager.loadPriceIntoCell( cell, 'golf_price', 'workday', 'general_bay', 'hourly' );

Example 2: Load Multiple Prices

const prices = [ { id: 'workday-hourly', table: 'golf_price', period: 'workday', category: 'general_bay', identity: 'hourly' }, { id: 'workday-student', table: 'golf_price', period: 'workday', category: 'general_bay', identity: 'student' }, { id: 'workday-disabled', table: 'golf_price', period: 'workday', category: 'general_bay', identity: 'disabled' }, ]; prices.forEach(price => { const element = document.getElementById(price.id); if (element) { priceManager.loadPriceIntoCell( element, price.table, price.period, price.category, price.identity ); } });

Example 3: Fetch Price Directly

// Fetch price without auto-loading into cell priceManager.fetchPrice('golf_price', 'workday', 'general_bay', 'hourly') .then(data => { if (data) { console.log('Current price: $' + data.price); } }) .catch(error => { console.error('Error:', error); });

Example 4: Update Price Manually

const cell = document.getElementById('price-cell'); const newPrice = 150; priceManager.savePrice(cell, newPrice); // User will see input box and save/cancel buttons

Example 5: Custom AJAX Call

// If you prefer to use fetch directly fetch('./price_api.php?action=get&table=golf_price&period=workday&price_category=general_bay&identity=hourly') .then(response => { if (!response.ok) throw new Error('API error'); return response.json(); }) .then(data => { if (data.success) { console.log('Price: $' + data.data.price); } else { console.error('Error: ' + data.error); } });

6️⃣ Troubleshooting

❌ Problem: "User not authenticated" error

Solution:

The API checks if user is logged in. Make sure user completed login at configuration-administraion.php first.

To debug: Open browser DevTools (F12) → Console and check the error response.

❌ Problem: Prices showing "-"

Solution:

This means no price exists for that combination. Double-check:

  • Table name is correct (golf_price or golf_price_2)
  • Period exists (workday, holiday, holiday_19To22)
  • price_category is valid
  • Price record exists in database

❌ Problem: JavaScript errors in console

Solution:
  • Check that price_manager.js file exists and is in root directory
  • Use F12 DevTools → Console to see detailed error messages
  • Check Network tab to see if AJAX requests are being made

❌ Problem: Edit button not showing

Solution:

User must be logged in. Make sure $_SESSION["management"] is set. Check in browser's Application tab → Cookies to verify session cookie exists.
